# Resume Builder Improvements (Revision 00)

## Context
- Source requirements: `docs/resume-builder/revisions-00.md`.
- Aligns with personas/principles in `docs/product/personas-and-ux.md` (mobile-first, guided, low-literacy support).
- Existing implementation: `apps/web/components/resume/ResumeBuilderSection.tsx`, templates under `apps/web/resume/templates/`.

## Tasks Snapshot
- **Template chooser**: add visual cards/descriptions so users know the style before generating.
- **Guided inputs**: add helper copy, tooltips, or inline hints for summary, experience bullets, etc.
- **Contact info**: collect phone + location (city, state) with privacy note; ensure required before download.
- **Skills entry**: switch from comma-separated string to chip/tag input with quick-add suggestions.
- **Experience timeline**: month-year selectors + “Present” handling to avoid free-form dates.
- **Ordering & clarity**: empty starter entries, reorder controls (drag/drop or move buttons), clearer “Add role” messaging.
- **AI rewrite UX**: show progress, compare original vs AI version, let user choose, highlight differences.
- **Responsive/sticky actions**: keep Generate/Reset visible on mobile; ensure buttons have accessible labels.
- **Resume output polish**: human-readable dates (e.g., `Jun 2021–Present`), improved contact line, reorder sections (Skills before Experience), richer sample bullet guidance.

## Open Questions / Decisions
- Drag-and-drop vs move buttons: lean toward keyboard-friendly move buttons for now.
- Diff highlighting: implement lightweight word-level diff without new dependency.
- Skill suggestions: provide curated list relevant to service roles (configurable for future).

## Implementation Notes
- Consider extracting subcomponents for template picker, skills input, experience timeline row to reduce complexity.
- Use local helper utilities for date formatting & diff to avoid pulling new packages (network restricted).
- Update Handlebars context helpers for date string formatting to keep templates clean.
- Ensure localStorage persistence adapts to new data shape (migrate if older draft present).
- Verify zod schema alignment after introducing required contact fields and new arrays ordering.
